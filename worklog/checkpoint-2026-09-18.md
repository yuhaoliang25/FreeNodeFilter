## 已确认的设计

### 来源

- 初始来源只作为种子。
- 后续来源可以由 GitHub 搜索、README 链接以及已知来源内容继续发现。
- 动态来源使用 URL 哈希作为稳定身份。
- 来源不会因为一次失败立即删除。
- 来源状态包含 candidate / normal / trusted / weak / degraded / dead 等生命周期信息。
- 来源信誉与节点实际测试分开维护。

### 节点

- 节点使用连接参数构成稳定 identity，而不是依赖显示名称。
- 去重后保留全部来源信息。
- 节点信誉使用近期历史测试，并逐渐积累长期证据。
- 新节点保留探索机会，不完全依赖历史信誉。
- 稳定结果需要多轮观测，不把一次成功视为稳定。

### 来源相似度

- 当前根据 endpoint identity 计算来源间 Jaccard overlap。
- 相似度用于描述信息相关性。
- 当前不会因为来源与其他来源高度重复而直接降低其质量信誉。
- independenceWeight 目前只作为分析数据。
- 后续如要用于调度或证据独立性判断，应先积累多个周期的历史数据。

## 暂停原因

该项目已经进入需要持续积累时间序列数据的阶段。

短期内不继续扩展主要功能。优先保留现有自动运行，让：
- 节点历史逐渐形成；
- 来源信誉逐渐形成；
- 来源相似度有更多时间维度；
- 后续可以基于真实历史数据决定是否调整探索/利用策略。

## 后续恢复时优先检查
